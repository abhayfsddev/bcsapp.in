📌 Project Overview

Frontend: React + Vite (SPA)

Backend: Node.js/Express + Nodemailer

Database: None (email-only)

Target: Hostinger hosting

1Choose Hostinger Plan

For your Node.js backend, you need a plan that supports Node.js applications.

Recommended Plans:

  • Cloud Hosting - Recommended for flexibility and performance
  • VPS - Full control, more expensive
  • NOT Shared Hosting - Limited Node.js support

What to do:

  1. Go to hostinger.com
  2. Choose: Cloud Hosting or VPS
  3. Select a plan and complete purchase
✅ You should receive hosting credentials via email

2Prepare Your Project

2.1 Build Frontend for Production

Navigate to your project root directory and run:

cd e:\dev\AI\React\fsmaster.in
npm run build

This creates a dist/ folder with optimized static files.

2.2 Verify Backend Requirements

Check that all backend dependencies are installed:

cd backend
npm list

You should see:

  • express
  • cors
  • body-parser
  • nodemailer
  • dotenv

3Access Hostinger Control Panel

  1. Login to Hostinger Dashboard: https://hpanel.hostinger.com
  2. Select your hosting account
  3. Go to: File Manager or Terminal (depending on your plan)

4Deploy Backend (Node.js)

These steps apply if you're using Cloud Hosting or VPS.

4.1 Connect via SSH

ssh root@your_server_ip
# Enter your password when prompted

4.2 Install Node.js

curl -sL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt install -y nodejs
node --version
npm --version

4.3 Create Project Directory

mkdir -p /var/www/fsmaster.in
cd /var/www/fsmaster.in

4.4 Upload Backend Files

Choose one method:

Option A - Using Git (Recommended):

git clone <your-repo-url> .
cd backend
npm install

Option B - Using SFTP:

  • Use FileZilla or WinSCP
  • Upload backend/ folder to /var/www/fsmaster.in/
  • Run: npm install

4.5 Set Up Environment Variables

nano /var/www/fsmaster.in/backend/.env

Add the following content:

EMAIL_USER=bcsopc@gmail.com
EMAIL_PASSWORD=your_app_password_here
RECIPIENT_EMAIL=bcsopc@gmail.com
FRONTEND_URL=https://yourdomain.com
NODE_ENV=production
PORT=5000
⚠️ Important: Use Gmail App Password, not your regular password. Generate one at https://myaccount.google.com/apppasswords

4.6 Install PM2 (Process Manager)

PM2 keeps your backend running 24/7:

sudo npm install -g pm2
cd /var/www/fsmaster.in/backend
pm2 start server.js --name "fsmaster-backend"
pm2 startup
pm2 save

5Deploy Frontend (React)

5.1 Upload Built Files

In your SSH terminal on Hostinger:

mkdir -p /var/www/fsmaster.in/public_html

# Copy built React files
cp -r /var/www/fsmaster.in/dist/* /var/www/fsmaster.in/public_html/

5.2 Configure for React Router

Create a .htaccess file in public_html/:

<IfModule mod_rewrite.c>
  RewriteEngine On
  RewriteBase /
  RewriteRule ^index\.html$ - [L]
  RewriteCond %{REQUEST_FILENAME} !-f
  RewriteCond %{REQUEST_FILENAME} !-d
  RewriteRule . /index.html [L]
</IfModule>

6Configure Domain

6.1 In Hostinger Dashboard:

  1. Go to Domains
  2. Add your domain: fsmaster.in
  3. Point DNS to Hostinger nameservers

6.2 Update Domain Registrar

If your domain is registered elsewhere, update the nameservers at your registrar to point to Hostinger.

⏱️ Wait 24-48 hours for DNS propagation

7Set Up SSL Certificate

Option A - Via Hostinger Dashboard:

  1. Go to SSL Certificate
  2. Click Install SSL (usually free with Let's Encrypt)
  3. Wait for installation (5-10 minutes)

Option B - Via SSH:

sudo apt install certbot python3-certbot-nginx
sudo certbot certonly --nginx -d fsmaster.in -d www.fsmaster.in

8Configure Reverse Proxy (Nginx)

Create Nginx configuration for routing:

sudo nano /etc/nginx/sites-available/fsmaster.in

Paste the following configuration:

server {
    listen 80;
    server_name fsmaster.in www.fsmaster.in;
    
    # Redirect HTTP to HTTPS
    return 301 https://$server_name$request_uri;
}

server {
    listen 443 ssl http2;
    server_name fsmaster.in www.fsmaster.in;
    
    # SSL certificates
    ssl_certificate /etc/letsencrypt/live/fsmaster.in/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/fsmaster.in/privkey.pem;
    
    # Frontend
    location / {
        root /var/www/fsmaster.in/public_html;
        try_files $uri $uri/ /index.html;
        index index.html;
    }
    
    # Backend API
    location /api/ {
        proxy_pass http://localhost:5000;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_cache_bypass $http_upgrade;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}

Enable the configuration:

sudo ln -s /etc/nginx/sites-available/fsmaster.in /etc/nginx/sites-enabled/
sudo nginx -t
sudo systemctl restart nginx

9Update Frontend API URL

Update your Contact.jsx to use your production domain:

const response = await fetch('https://fsmaster.in/api/send-email', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json',
  },
  body: JSON.stringify({
    name: formData.name,
    email: formData.email,
    subject: formData.subject,
    message: formData.message,
  }),
});

Or use Environment Variables:

Create .env.production:

VITE_API_URL=https://fsmaster.in/api

Then in your component:

const apiUrl = import.meta.env.VITE_API_URL || '/api';
const response = await fetch(`${apiUrl}/send-email`, { ... });

11Monitoring & Maintenance

Check Backend Status:

pm2 status
pm2 logs fsmaster-backend

Update Backend Code:

cd /var/www/fsmaster.in/backend
git pull
npm install
pm2 restart fsmaster-backend

Renew SSL Certificate:

sudo certbot renew --dry-run

Let's Encrypt certificates auto-renew, but you can manually check with the command above.

🔧 Common Issues & Solutions

Issue Solution
API not reachable (CORS error) Check /api/ proxy config in Nginx configuration
Backend not starting Check logs: pm2 logs
Emails not sending Verify Gmail App Password in .env file
Domain not working Wait for DNS propagation (24-48 hours)
SSL certificate error Reinstall SSL from Hostinger dashboard
404 errors on page refresh Ensure .htaccess is in public_html/ folder
